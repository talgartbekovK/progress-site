# Прогресс

Сайт и локальная админка образовательного центра. Сервер использует Python и SQLite, дополнительные пакеты не требуются.

## Запуск в PowerShell

Из папки проекта:

```powershell
python server.py create-admin --login owner  # только для новой базы
python server.py serve
```

Нужен Python 3. Если команда `python` недоступна, используйте полный путь к установленному `python.exe`. При создании администратора пароль вводится в консоли и сохраняется только как хеш. Затем откройте [сайт](http://127.0.0.1:4173/) или [админку](http://127.0.0.1:4173/admin.html). Сервер доступен только на этом компьютере (`127.0.0.1`). База хранится в `data/progress.sqlite3` и исключена из Git; сделайте отдельную резервную копию перед работой с реальными данными.

## Роли

- **Администратор:** видит регистрации и заявки, создаёт преподавателей, добавляет и редактирует учеников, архивирует их, создаёт и публикует тесты и видеоссылки.
- **Преподаватель:** видит только назначенных учеников, отмечает посещаемость и оставляет комментарии.
- **Родитель:** самостоятельно регистрируется, затем администратор привязывает к нему ребёнка. Просмотр данных ребёнка доступен только после входа.

Пароль преподавателя вводится администратором при создании аккаунта и показывается на экране один раз. Сообщите его преподавателю лично по подходящему для вас защищённому каналу. Платные тесты видны как закрытые до подключения оплаты. Видео добавляется по HTTPS-ссылке. Отправка заявок в WhatsApp, приём платежей и публикация сайта в интернет пока не подключены.

Если пароль нужно заменить, выполните `python server.py set-password --login ЛОГИН`. Старые сеансы пользователя будут завершены.

## PythonAnywhere (бесплатный предпросмотр с базой)

Создайте веб-приложение через **Web → Add a new web app → Manual configuration**. В Bash-консоли клонируйте репозиторий:

```bash
git clone https://github.com/talgartbekovK/progress-site.git ~/progress-site
```

В WSGI-файле, указанном на странице Web, оставьте:

```python
import sys
path = '/home/YOUR_USERNAME/progress-site'
if path not in sys.path:
    sys.path.insert(0, path)
from wsgi import application
```

Замените `YOUR_USERNAME` на логин PythonAnywhere. В Bash-консоли выполните `cd ~/progress-site && python3 server.py create-admin --login owner`; введите новый пароль без отображения на экране. Затем нажмите **Reload** на странице Web и откройте `https://YOUR_USERNAME.pythonanywhere.com/admin.html`.

При следующих изменениях кода выполните `git pull` в папке проекта на PythonAnywhere и снова нажмите **Reload**. SQLite-файл в `data/` хранится отдельно от Git. Для бесплатного аккаунта необходимо вовремя продлевать веб-приложение в панели PythonAnywhere.

## Проверка

```powershell
python -m unittest discover -s tests -q
```

Проверка использует временную базу и не меняет рабочие данные.
